# Experimental Digital Art

A generative art playground built with PixiJS and ToneJS, designed for immersive viewing experiences.

## Artistic Vision

- **Ancient Runes & Alien Technology**: Crop circles, Da Vinci's mechanical drawings, alien hieroglyphs
- **High Contrast Pixel Art**: Technically simple graphics that are mesmerizing in composition
- **Clockwork Mechanisms**: Mesmerizing, precise movements that feel both organic and mechanical
- **God's Eye Perspective**: Designs viewed from above or another dimension
- **Sacred Geometry**: Golden ratios, fibonacci sequences, platonic solids

## Technical Approach

- 60fps performance-optimized animations
- Time-based generative systems
- Audio-visual synchronization (shared frequencies and variables)
- Pixel-perfect geometric rendering
- Headless browser deployment

## Development Philosophy

- **Messy Studio Mentality**: Ideation over perfection, rapid experimentation
- **Playground Environment**: Quick iteration, throwaway experiments
- **No User Interaction**: Pure generative experiences
- **Dedicated Hardware**: MacBook Pro performance for complex compositions

## Development

- `yarn start` - Start dev server and launch Chrome in kiosk mode
- `yarn build` - Build for production
- Press 'M' to toggle audio during development
